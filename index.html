The Game

Every run is a
new descent.

The Dark Crown: Genesis is a fast-paced 2D action rogue-lite set in a dying kingdom swallowed by darkness. Each run you go deeper, hit harder, and build something new.

No two runs play the same. Weapons, relics, and upgrades combine in ways that reward experimentation and punish hesitation.
